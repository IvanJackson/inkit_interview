# Data Model: Streaming Chat Responses

**Feature**: 002-streaming-responses
**Date**: 2026-02-16

## Entities

### SSE Chunk (Value Object — not persisted)

Represents a single Server-Sent Event in the streaming response. Chunks are ephemeral — generated and sent immediately, never stored.

| Field           | Type              | Description                                      |
|-----------------|-------------------|--------------------------------------------------|
| id              | string            | Shared across all chunks in one completion (e.g., `chatcmpl-abc123`) |
| object          | string (constant) | Always `"chat.completion.chunk"`                 |
| created         | integer           | Unix timestamp, shared across all chunks         |
| model           | string            | Model name (e.g., `"gpt-4-vision-preview"`)      |
| choices         | array             | Single-element array containing the choice       |
| choices[0].index | integer           | Always `0`                                       |
| choices[0].delta | object            | Incremental content (replaces `message`)         |
| choices[0].logprobs | null           | Not used in mock                                 |
| choices[0].finish_reason | string/null | `null` during streaming, `"stop"` on final chunk |
| usage           | object/null       | `null` on all chunks except final usage chunk    |
| service_tier    | string            | Always `"default"`                               |
| system_fingerprint | null           | Not used in mock                                 |

### Delta (Embedded Object)

The incremental content within a chunk's choice. Three variants:

| Variant      | Fields                          | When emitted          |
|-------------|--------------------------------|-----------------------|
| Role        | `{ role: "assistant", content: "" }` | First chunk          |
| Content     | `{ content: "token text" }`    | Each content token    |
| Empty       | `{}`                           | Stop and usage chunks |

### Stream Connection (Runtime State — not persisted)

Tracks an active SSE connection for concurrency and timeout management.

| Attribute     | Type    | Description                                    |
|---------------|---------|------------------------------------------------|
| start_time    | float   | `time.time()` when stream started              |
| is_active     | boolean | Whether the generator is still yielding        |

**Note**: Stream connections are managed via a `BoundedSemaphore` counter, not individual connection objects. The semaphore tracks how many connections are active without needing per-connection state.

## Configuration Values (New)

| Config Key                  | Type    | Default | Description                          |
|----------------------------|---------|---------|--------------------------------------|
| MAX_STREAMING_CONNECTIONS  | integer | 50      | Maximum concurrent SSE connections   |
| STREAM_TIMEOUT_SECONDS     | integer | 30      | Maximum duration of a single stream  |

## Relationships

- **SSE Chunk** → generated by `mock_openai_service._stream_response()`
- **SSE Chunk** → formatted by `openai_formatter.format_stream_chunk()`
- **Stream Connection** → managed by semaphore in `chat.py` endpoint
- **Stream Connection** → timeout tracked inside generator loop

## No Schema Changes

This feature introduces no persistent entities. All streaming state is ephemeral and managed in-memory during the request lifecycle. Existing models (`ChatRequest`, `SessionContext`, `QueuedRequest`) are unchanged.

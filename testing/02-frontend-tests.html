🌐 Frontend Tests

These tests validate frontend functionality. Some require manual interaction.

Test 1: Image Upload UI

🌐 Manual Test: Upload an image using the main interface

  1. Open main app at http://localhost:5001
  2. Click the paperclip icon or drag & drop an image
  3. Verify you see the upload preview and metadata
  4. Check browser console for any errors
✅ Expected: Image preview, metadata display, streaming analysis ❌ Issues: No preview, console errors, upload failures

Test 2: New Image Conversation

🌐 Manual Test: Verify new conversation behavior

  1. Upload first image and send a message
  2. Upload a second image without sending a message
  3. Verify you see "🆕 Uploading a new image will start a fresh conversation thread"
  4. Verify the first conversation appears in history
✅ Expected: Clear messaging about new conversation, history preservation ❌ Issues: No warning message, conversation lost

Test 3: Chat Without Image

🌐 Manual Test: Try to chat without uploading image

  1. Open the app without uploading any image
  2. Type a message and try to send
  3. Verify you see error message about requiring image
✅ Expected: "Please upload an image to start a conversation" ❌ Issues: Message sends without image, no error shown

Test 4: Streaming Display

🌐 Manual Test: Verify streaming text appears in real-time

  1. Open browser developer console (F12)
  2. Upload an image and send a message
  3. Watch console for "SSE Chunk:" and "Delta content:" messages
  4. Verify text appears word by word in the chat bubble
✅ Expected: Console logs showing chunks, text appearing progressively ❌ Issues: No console logs, text appears all at once, invisible text

Test 5: History Panel

🌐 Manual Test: Test conversation history functionality

  1. Have multiple conversations with different images
  2. Click the 📚 History button
  3. Verify you see all conversations (up to 100)
  4. Click on a past conversation to load it
  5. Verify the correct image and messages appear
✅ Expected: All conversations visible, correct loading ❌ Issues: Missing conversations, broken loading, wrong image
